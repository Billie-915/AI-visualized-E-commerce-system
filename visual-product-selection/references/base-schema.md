# 飞书多维表格建议结构

## `产品调研`

| 字段 | 类型 | 说明 |
|---|---|---|
| 产品名称 | 文本 | 品牌+型号或官方产品名 |
| 品牌 | 多选/文本 | 统一品牌名 |
| 型号 | 文本 | 官方型号 |
| 价格下限 | 数字 | 公开/常规价格下限，单位元 |
| 价格上限 | 数字 | 公开/常规价格上限，单位元 |
| 价格带 | 单选 | 例如 300–699元、699–899元、1299–1699元、2000元以上 |
| 618参考价 | 数字 | 活动券后到手价；无法确认时留空 |
| 核心卖点 | 多行文本 | 1–3条可验证卖点 |
| 差评痛点 | 多行文本 | 评论/实测归纳，区分事实与推断 |
| 适合人群 | 多行文本 | 预算、体型、时长、使用场景 |
| 关键参数/功能 | 多行文本 | 影响购买决策的参数 |
| 选品评分 | 数字 | 评分规则需在文档中公开 |
| 618建议 | 单选/多选 | 首发主推、重点关注、可做对比款、谨慎引入、价格锚点 |
| 证据等级 | 单选 | 官方/电商、第三方实测、榜单/促销、用户反馈、推断 |
| 来源链接 | URL | 至少一个可追溯来源 |
| 调研日期 | 日期 | YYYY-MM-DD |
| 调研批次 | 文本 | 例如 2026-618-01；便于追加历史批次 |

## `618选品结论`

| 字段 | 类型 | 说明 |
|---|---|---|
| 策略层级 | 单选 | 引流爆款、利润主推、结构升级、高端形象、价格锚点 |
| 建议零售价 | 文本 | 公开/原价区间 |
| 建议618到手价 | 文本 | 券后或活动到手区间，必须写清口径 |
| 目标人群 | 多行文本 | 具体到场景和体型/预算 |
| 建议主打配置 | 多行文本 | 只放能形成差异化的配置 |
| 核心传播话术 | 多行文本 | 一句话表达用户收益 |
| 竞品参考 | 多行文本 | 关联产品名称或记录 ID |
| 主要风险 | 多行文本 | 产品、体验、供应链、售后、价格风险 |
| 优先级 | 数字 | 5最高，或使用 P0/P1/P2 单选；全项目保持一致 |
| 下一步动作 | 多行文本 | 打样、试坐、素材、成本、供应链动作 |
| 来源说明 | 多行文本 | 说明结论来自哪些样本和证据 |
| 调研批次 | 文本 | 与产品调研批次对应 |

## 评分建议

如果用户没有给评分规则，使用 1–5 分，并在文档中公开维度：需求强度、体验差异、价格竞争力、毛利空间、供应链/售后可控性。评分是决策辅助，不要把它描述成平台真实销量或市场份额。
