# 每日可视化运营日报

## 目标

把每日经营数据翻译成老板能直接做决策的日报。重点回答：今天生意怎么样、风险在哪里、增长来自哪里、明天先做什么，而不是只罗列数字。

## 项目边界

- 只读取当前项目根目录及 `data/`、`docs/`、`output/`、`feishu/` 中的文件。
- 先读取项目根目录的 `AGENT.md`，其业务规则优先于本技能。
- 不访问项目外文件。用户给出项目外数据时，请其先放入 `data/`。
- 默认只生成本地文件。只有用户明确要求并确认目标文档或画板时，才写入真实飞书。

## 输入选择

1. 优先使用用户明确指定的 CSV 和日期。
2. 用户只说“今天”时，优先查找 `data/daily_metrics_YYYY-MM-DD.csv`。
3. 未指定日期时，使用数据中的最新日期。
4. `data/daily_metrics_template.csv` 仅用于模板或模拟演示。没有真实今日数据时，不要把模板伪装成真实经营结果。
5. 结合 `docs/business_context.md` 解释活动、产品、竞品和历史复盘背景。

核心字段包括：

`date, store, channel, product_name, product_id, sku, gmv, orders, average_order_value, cost, profit, profit_margin, refund_rate, roi, inventory, material_impressions, material_clicks, material_ctr, live_viewers, live_buyers, live_conversion_rate, notes`

缺少字段时，明确列出缺失项以及受影响的判断，不要强行得出完整结论。

## 隐私处理

检测姓名、手机号、地址、订单号、账号 ID、身份证号等真实客户字段。分析和输出前先脱敏，不在日报、日志或飞书内容中复述原始敏感值。

## 执行流程

1. 确认输入文件、日期和数据性质（真实或模拟）。
2. 检查字段、空值、重复行、百分比口径和金额口径。
3. 在项目根目录运行：

```powershell
python workflow.py daily-report --input data/daily_metrics_YYYY-MM-DD.csv --date YYYY-MM-DD
```

省略 `--date` 时使用数据中的最新日期。

4. 读取生成的 `output/daily_report_YYYY-MM-DD.md`，按下方规则做最终质量检查。
5. 向用户先摘要经营结论，再提供输出文件链接。

## 判断规则

- 利润率低于 30%：标记利润风险，并检查成本、售价和投放结构。表达为“能卖，但赚钱质量不够”，不要只写“利润率偏低”。
- 退款率相对历史明显上升：提醒检查产品质量、尺码/规格、物流时效和客服话术。
- 没有历史数据但当前退款率达到 10%：只提示当前高退款风险，不假定趋势。
- GMV 高但 ROI 低：提醒确认增长是否靠投放硬拉，避免销售增长掩盖利润损耗。
- 素材点击率高但成交承接低：检查详情页、价格、信任感、直播讲解和人群匹配。
- 销量高且库存只能覆盖短期订单：提示补货和断货风险。
- 数据不足：明确说明缺什么，以及哪些结论只能作为初步参考。

## 固定输出结构

日报先结论后数据，使用以下顺序：

```markdown
# 每日可视化运营日报 - YYYY-MM-DD

## 今日经营结论
## 关键风险提醒
## 增长机会
## 明日动作建议
## 核心数据表现
## 商品/渠道/直播/素材明细
## 业务背景参考
```

经营结论控制在 3-5 条。每条明日动作包含动作、原因和关注指标，并优先按商品、投放、素材、直播、库存、客服组织。

## 表达要求

- 使用“经营判断 + 数据依据 + 下一步动作”的表达方式。
- 使用 GMV、订单量、利润、退款率和 ROI 等通用指标名，但避免财务黑话。
- 不要把“数据上涨/下跌”当作结论，要说明为什么重要以及下一步怎么做。
- 给老板看的正文保持短句、可扫描、可直接转发。

## 飞书扩展

用户明确要求飞书版本时：

1. 先生成并检查本地日报。
2. 需要画板结构时运行 `python workflow.py feishu-board --input <CSV> --date <日期>`。
3. 画板按经营结论、核心指标、风险提醒、商品矩阵、增长机会、下一步动作分区。
4. 真实写入前确认目标文档或画板 token，写入后返回飞书链接。

## 完成标准

- 日报第一部分是经营结论，不是数据表。
- 关键指标至少覆盖 GMV、订单、成本、利润、利润率、退款率、ROI 和库存。
- 利润率低于 30% 和退款异常规则正确触发。
- 包含风险提醒、增长机会和可执行的明日动作。
- 真实客户信息已脱敏。
- 输出只写入 `output/` 或经确认的飞书目标。
